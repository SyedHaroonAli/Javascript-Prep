# JavaScript Problem Set 2 — Easy to Medium

## Problem 1 — Palindrome Checker

Write a function that checks whether a string is a palindrome.

A palindrome reads the same forwards and backwards.

Example:

```js id="5x2k9q"
isPalindrome('madam')
```

Output:

```js id="9p4v1n"
true
```

Example:

```js id="3m8q7l"
isPalindrome('hello')
```

Output:

```js id="k2d9sa"
false
```

## Problem 2 — FizzBuzz

Print numbers from `1` to `100`.

Rules:

- If divisible by `3` → print `"Fizz"`
- If divisible by `5` → print `"Buzz"`
- If divisible by both → print `"FizzBuzz"`
- Otherwise print the number

Example:

```txt id="6t9n4w"
1
2
Fizz
4
Buzz
Fizz
...
```

## Problem 3 — Remove Duplicates From Array

Write a function that removes duplicate values from an array.

Example:

```js id="z7x4qe"
removeDuplicates([1, 2, 2, 3, 4, 4])
```

Output:

```js id="d5m2ka"
;[1, 2, 3, 4]
```

## Problem 4 — Find Frequency of Characters

Write a function that returns the frequency/count of each character in a string.

Example:

```js id="7w3lpd"
charFrequency('hello')
```

Output:

```js id="x8n5ov"
{
  h: 1,
  e: 1,
  l: 2,
  o: 1
}
```

## Problem 5 — Flatten an Array (Single Level)

Write a function that flattens a nested array by one level.

Example:

```js id="1v0mqs"
flatten([1, [2, 3], [4, 5]])
```

Output:

```js id="j9p2xl"
;[1, 2, 3, 4, 5]
```

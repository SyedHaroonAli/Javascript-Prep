# Contributing to Javascript Prep

Thank you for your interest in contributing! We welcome your help to improve this project.

## How to Contribute

### 1. Reporting Bugs
* Search existing issues to avoid making duplicates.
* Open a new issue if your bug hasn't been reported.
* Describe the problem clearly and include steps to reproduce it.

### 2. Submitting Pull Requests (PRs)
1. Fork this repository to your own account.
2. Clone your fork locally and create a new branch.
3. Make your changes and commit them with clear messages.
4. Push your branch to GitHub
5. Submit a pull request to our `main` branch.

## Code of Conduct
* Be respectful, friendly, and constructive in all interactions.

# Introduction to Data Analytics

## What is Data Analytics?

Data Analytics is the process of collecting, cleaning, transforming, and analyzing data to discover useful information, identify patterns, and support decision-making.

Simply put:

> Data Analytics helps organizations turn raw data into meaningful insights.

---

# Why is Data Analytics Important?

Organizations generate large amounts of data every day:

- Sales transactions
- Customer interactions
- Website visits
- Phone calls
- Social media activity
- Financial records

Data Analytics helps answer questions such as:

- Which products sell the most?
- Which customers are most valuable?
- Why are sales declining?
- What trends are emerging?
- How can business performance be improved?

---

# What is Data?

Data is a collection of facts, observations, or measurements.

### Examples

| Customer Name | City      | Purchase Amount |
| ------------- | --------- | --------------- |
| John          | Hyderabad | 5000            |
| Sarah         | Mumbai    | 7500            |
| Ali           | Delhi     | 3000            |

This information is called **raw data**.

---

# Data vs Information

### Data

Raw facts without context.

Example:

```txt
5000
7500
3000
```

### Information

Processed data that provides meaning.

Example:

```txt
Average Purchase Amount = 5166.67
```

# Data Analytics Process

## 1. Data Collection

Gather data from various sources.

Sources include:

- Databases
- Excel Sheets
- CRM Systems
- APIs
- Surveys
- Websites

---

## 2. Data Cleaning

Fix errors and inconsistencies.

Examples:

- Remove duplicate records
- Handle missing values
- Correct invalid entries

Example:

```txt
John, Hyderabad
John, Hyderabad
```

After cleaning:

```txt
John, Hyderabad
```

---

## 3. Data Transformation

Convert data into a suitable format.

Examples:

- Combining datasets
- Formatting dates
- Calculating totals

---

## 4. Data Analysis

Apply statistical and analytical techniques to identify trends and patterns.

Example:

```txt
Monthly Sales Analysis
```

| Month | Sales |
| ----- | ----- |
| Jan   | 10000 |
| Feb   | 12000 |
| Mar   | 18000 |

Observation:

Sales are increasing month-over-month.

---

## 5. Data Visualization

Present findings using charts and dashboards.

Common visualizations:

- Bar Charts
- Pie Charts
- Line Charts
- Dashboards
- Heat Maps

---

# Types of Data Analytics

## 1. Descriptive Analytics

Answers:

> What happened?

Example:

```txt
Sales last month were ₹50 Lakhs.
```

---

## 2. Diagnostic Analytics

Answers:

> Why did it happen?

Example:

```txt
Sales increased because of a marketing campaign.
```

---

## 3. Predictive Analytics

Answers:

> What is likely to happen?

Example:

```txt
Expected sales next month: ₹60 Lakhs.
```

Uses:

- Machine Learning
- Forecasting Models

---

## 4. Prescriptive Analytics

Answers:

> What should we do?

Example:

```txt
Increase advertising spend in high-performing regions.
```

---

# Key Concepts

## Dataset

A collection of related data.

Example:

Customer database.

---

## Record (Row)

A single entry in a dataset.

Example:

```txt
John | Hyderabad | 5000
```

---

## Field (Column)

A specific attribute of data.

Example:

```txt
Customer Name
City
Purchase Amount
```

---

## Metric

A measurable value used for analysis.

Examples:

- Revenue
- Profit
- Number of Calls
- Customer Count

---

## KPI (Key Performance Indicator)

A metric used to measure business performance.

Examples:

- Monthly Revenue
- Conversion Rate
- Customer Retention Rate
- Average Call Duration

# Real-World Example

Suppose a CRM stores:

| Lead ID | Calls Made | Status |
| ------- | ---------- | ------ |
| 1       | 10         | Won    |

Questions Data Analytics can answer:

- How many leads were won?
